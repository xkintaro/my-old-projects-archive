## 📋 About

**EN - ENGLISH**

In this project, I tried building a multilingual authentication system. Even the URLs were designed to fully support multiple languages. I also secured the /admin route so unauthorized access returns a 404, making it impossible to even tell an admin panel exists. Right now, the project only includes i18n, basic authentication features, and a simple admin dashboard — no CRUD systems yet. I’ve paused development for now, but it’s a solid foundation to keep around in case I need it later.

##

**TR - TÜRKÇE**

Bu projede çok dilli bir kullanıcı kayıt/giriş sistemi altyapısı oluşturmaya çalıştım. Sistem, URL yapısına kadar tamamen çok dilli olacak şekilde tasarlandı. Ayrıca /admin rotasını da koruma altına aldım; yetkisiz erişimlerde doğrudan 404 döndürdüğü için admin panelinin varlığı bile anlaşılmıyor. Şu anda sadece i18n, temel kullanıcı kayıt/giriş işlemleri ve basit admin dashboard özellikleri bulunuyor. CRUD gibi detaylı sistemler henüz yok. Şimdilik projeye ara verdim ama ileride lazım olursa diye hazır bir altyapı olarak burada duruyor.
